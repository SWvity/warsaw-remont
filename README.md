# WARSAW REMONT — strona internetowa

## Pliki
- `index.html` — treść strony (język polski)
- `style.css` — wygląd, responsywność i animacje
- `script.js` — menu mobilne, animacje przy przewijaniu i formularz e-mail

## Co zmienić przed publikacją
W `index.html`:
1. Numer telefonu, e-mail oraz linki do Instagramu, Telegramu i Facebooka zostały już uzupełnione.
2. Zastąp zdjęcia poglądowe zdjęciami swoich realizacji. Obecne zdjęcia są pobierane z Unsplash.
3. Uzupełnij opis firmy i zakres usług tak, aby odpowiadał faktycznie wykonywanym pracom.

## Publikacja przez GitHub Pages
1. Zaloguj się na https://github.com i utwórz nowe publiczne repozytorium, np. `warsaw-remont`.
2. Wgraj do repozytorium trzy pliki: `index.html`, `style.css`, `script.js`.
3. Otwórz **Settings → Pages**.
4. W sekcji **Build and deployment** wybierz **Deploy from a branch**.
5. Wybierz branch `main` i folder `/ (root)`, a następnie **Save**.
6. Po chwili GitHub pokaże adres strony w sekcji Pages, zwykle `https://TWOJ-LOGIN.github.io/warsaw-remont/`.

To jest statyczna strona — Python ani serwer nie są potrzebne. Formularz przygotowuje wiadomość e-mail przez aplikację pocztową użytkownika; nie zapisuje zgłoszeń w bazie danych.
