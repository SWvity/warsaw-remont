# WARSAW REMONT — aktualizacja kontaktów

Polska strona wizytówka firmy remontowej w Warszawie.

## Pliki
- `index.html` — treść strony i linki kontaktowe
- `style.css` — wygląd, responsywność i animacje
- `script.js` — menu, animacje przewijania i formularz SMS

## Formularz SMS
Formularz otwiera domyślną aplikację SMS w telefonie z przygotowaną wiadomością na numer +48 519 465 199. Klient musi sam nacisnąć przycisk „Wyślij”. Strona statyczna GitHub Pages nie wysyła SMS-ów automatycznie.

## Publikacja
W repozytorium GitHub zastąp pliki `index.html`, `style.css` i `script.js` wersjami z tego archiwum, a następnie zatwierdź zmiany (Commit changes). Ustawienia GitHub Pages pozostają bez zmian.
